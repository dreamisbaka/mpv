# mpv 个人配置

由于单文件大小限制，本仓库不含 mpv 本体，请参考下方说明

## 用法

1. 下载 [mpv 本体](https://mpv.io/installation/)  
对于 Windows 用户来说，shinchiro 或 zhongfly 的版本都行
2. 下载或 clone 本仓库，将 portable_config 文件夹放在 mpv.exe 旁
3. 执行 mpv-register.bat 以注册文件关联，之后即可正常播放视频
